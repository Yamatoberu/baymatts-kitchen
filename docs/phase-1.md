# Phase 1 recipe library

The README is the product vision. This release provides a runnable personal recipe library.

Acceptance criteria

- Create, read, edit, delete and search recipes through the browser.
- Store structured ingredient quantities, units and preparation notes, and ordered instructions.
- Preserve attribution and original source references.
- Record nutritional estimates and known or potential allergens.
- Show per-serving nutrition and scale quantities for a chosen serving count.
- Preserve earlier recipe revisions after edits and expose them in the UI.
- Persist recipes across server restarts.
- Support the requested Neon PostgreSQL storage through DATABASE_URL.
- Provide local durable storage so development can run without cloud credentials.
- Document installation, checks, storage selection and remaining deployment requirements.

Meal planning, pantry inventory and grocery lists remain future phases in the product README.
